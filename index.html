🗄️ bd2.sh — Guía Interactiva

Automatiza la descarga, restauración y neutralización segura de bases de datos Odoo en PostgreSQL local desde archivos .zip, .sql, .dump o instaladores .sh de Deploy Manager.

⚡ Generador Interactivo de Comando

./bd2.sh mi_proyecto_local -file install-instancia_2026-11-12.sh

💡 Extrae RESTORE_TOKEN y RESTORE_URL del script instalador, descarga únicamente la BD en local (sin filestore, sin clonar código y sin levantar contenedores) y aplica todas las neutralizaciones.

🚀 Modos de Ejecución

Instalador .sh -file / --file

Toma un archivo install-*.sh descargado del Deploy Manager y restaura solo la base de datos en tu PostgreSQL local.

./bd2.sh -file install-instancia.sh
./bd2.sh mi_bd -file install-instancia.sh

Archivo ZIP por defecto / -f

Descomprime ~/Downloads/nombre_bd.zip, restaura el SQL interno y opcionalmente copia el filestore con -f.

./bd2.sh mi_bd
./bd2.sh mi_bd -f

SQL Directo -sql / --sql

Carga directamente ~/Downloads/nombre_bd.sql sin descomprimir archivos ni tocar el filestore.

./bd2.sh mi_bd -sql

DUMP / PGC Binario -dump / --dump

Restaura archivos PGDMP con pg_restore -j 4. Detecta soporte zstd automáticamente o usa Docker como respaldo.

./bd2.sh mi_bd -dump

Solo Neutralizar -config

Ejecuta únicamente las reglas de neutralización, credenciales de prueba y limpieza de assets sobre una BD que ya existe.

./bd2.sh mi_bd -config

Validación Inteligente Automático

Verifica los encabezados reales del archivo (PGDMP, ZIP, SQL, SH) antes de borrar la BD y sugiere el comando correcto si no coincide.

./bd2.sh -doc   # Abre esta guía

🛡️ Neutralización Automática (SQL Directo, sin cintillo)

Componente Tabla / Parámetro Acción Aplicada
UUID y Secreto de BD ir_config_parameter Regenera database.uuid y database.secret con gen_random_uuid() y elimina database.enterprise_code.
Accesos de Desarrollo res_users Establece login = 'admin' (id=2) y contraseña 1 para los usuarios; reemplaza correos y teléfonos en res_partner.
Correos y Colas ir_mail_server, fetchmail_server, mail_mail Elimina servidores SMTP salientes, desactiva servidores entrantes, limpia colas pendientes y desvincula plantillas.
Tareas Programadas ir_cron Desactiva todos los crons (active = false) para evitar ejecuciones automáticas en local.
Facturación PAC (MX) res_company (edi / cfdi) Configura automáticamente las credenciales de prueba de Solución Factible (test_env = true).
IAP, OAuth, Pagos y Webhooks iap_account, auth_oauth_provider, payment_provider Deshabilita tokens IAP (+disabled), proveedores OAuth, pasarelas de pago productivas, dominios de Website y webhooks.
Assets y Sesiones ir_asset, ir_attachment, ir_module_module Limpia assets compilados (/web/assets/%, /_custom/%) y desinstala solt_session_valkey si viene del instalador.
